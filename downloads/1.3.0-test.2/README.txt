MC Auto Translation Tool 1.3.0-test.2

这是测试版，不会替代 GitHub 上的 Latest 正式版。

请只安装一个与 Minecraft 版本和加载器完全匹配的 JAR：
- Forge 1.8.9、1.12.2、1.16.5、1.19.2、1.20.1：使用文件名中的精确版本 JAR。
- Fabric 1.16.5、1.19.2、1.20.1：使用文件名中的精确版本 JAR，并安装对应 Fabric API。
- Fabric 1.21–1.21.11：使用 mc1.21.x-fabric 单一 JAR，Loader 会选择内嵌的精确实现。
- Forge 1.21、1.21.1、1.21.3–1.21.11：使用文件名中的精确版本 JAR；Forge 没有 1.21.2 目标。
- Fabric 26.1–26.2：使用 mc26.x-fabric 单一 JAR，Loader 会选择内嵌的精确实现。
- Forge 26.1、26.1.1、26.1.2、26.2：使用文件名中的精确版本 JAR。

本版包含：
- 自动翻译模组菜单、任务书、配方/物品界面和整合包自定义标题等使用 Minecraft 标准字体渲染的内容。
- 可选的发送聊天翻译：在设置中启用后，把玩家输入异步翻译到单独选择的目标语言；命令保持原样。
- 旧版及新版 Forge 启动兼容修复，以及 Fabric 1.16.5 依赖修复。

重要限制：
- 图片文字或完全绕过 Minecraft 标准字体渲染器的自定义界面无法自动捕获。
- 自动翻译和发送聊天翻译默认关闭；请先配置翻译服务，并在设置中按需启用。
- 建议先备份配置和存档，并使用 SHA256SUMS.txt 校验文件。
