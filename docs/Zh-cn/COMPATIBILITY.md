## “支持所有版本”的原则

Minecraft 各时代的加载器、Java 版本、渲染 API 和文字组件结构不同，无法用一个
JAR 安全覆盖所有 Java 版。项目会按有代表性的长期使用版本逐条适配，并为每条发布线
保留独立 JAR。只有完成构建、启动、服务器内界面回归后，才会进入“已验证”表。

后续候选顺序：

1. 1.12.2 Cleanroom；
2. 1.7.10 Forge；
3. 1.16.5 Forge；
4. 1.18.2 Forge/Fabric；
5. 1.21.1 Fabric/NeoForge；
6. 后续仍有较多玩家使用的新版本。

“相邻版本”不会通过放宽 `fabric.mod.json` 或 `mods.toml` 的版本范围来猜测支持。
例如 1.20.1 的 JAR 明确拒绝 1.20.2，Fabric 与 Forge 也绝不混用。这样能避免方法描述符
或事件 ABI 的细微变化在启动时导致 Mixin 失败。相邻版本会复用共享核心，但必须新增
独立平台适配并通过同一套构建、映射、启动和服务器内回归后才能正式列入。

## 服务器内回归清单

- 聊天、记分板、Tab 列表、Action Bar、标题和 Boss Bar；
- 箱子/菜单标题、物品名与 Lore、告示牌、书、实体名和全息文字；
- 未进入世界时的模组设置页、任务书、配方界面和整合包自定义标题屏；
- 模组/整合包文字使用原版字体渲染器时可捕获，图片文字和自带渲染器明确列为限制；
- 玩家自己输入和发出的聊天保持原文；
- 在线玩家名称、本机名称、服务器 IP/域名/端口保持原样；
- 已有中文不重复翻译，英文片段可翻译；
- 仅译文模式无双语溢出，颜色选项生效；
- `U` 控制面板和 `F8` 总开关在不同窗口尺寸下可用；
- 模型下载中、下载失败、离线引擎失败时游戏不冻结，继续显示原文。
