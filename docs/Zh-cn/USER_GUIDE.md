# MC 自动翻译工具安装与使用指南

[简体中文](USER_GUIDE.md) · [繁體中文](../Zh-tw/USER_GUIDE.md) · [English](../en/USER_GUIDE.md) · [返回简中 README](README.md)

## 选择正确的文件

每个 Minecraft 版本必须使用对应 JAR，不能混用：

| Minecraft | 模组加载器 | Java | 还需要 |
| --- | --- | --- | --- |
| 26.1、26.1.1、26.1.2、26.2（单一 JAR） | Fabric | 25 | 对应版本的 Fabric API |
| 1.21–1.21.11（单一 JAR） | Fabric | 21 | 对应版本的 Fabric API |
| 1.21.11 | Forge 61.2.0+ | 21 | 无额外模组 |
| 1.21.11 | Fabric | 21 | Fabric API |
| 1.20.1 | Forge 47.4.10+ | 17 | 无额外模组 |
| 1.20.1 | Fabric | 17 | Fabric API |
| 1.19.2（尚未发布 JAR） | Fabric | 17 | Fabric API |
| 1.16.5（尚未发布 JAR） | Fabric | 8 | Fabric API |
| 1.12.2 | Forge 14.23.5.x | 8 | 无额外模组 |
| 1.8.9 | Forge 11.15.1.x | 8 | 无额外模组 |

把正确的 JAR 放入该游戏实例的 `mods` 文件夹。服务器不需要安装本模组。
1.20.1 与 1.21.11 的 JAR 只支持表中精确版本，不能用于相邻版本，也不能在 Fabric
和 Forge 之间混用。

## 第一次设置

以下图形设置步骤适用于 Fabric 和旧版 Forge。Forge 1.20.1/1.21.11 首次启动后会生成
`config/universal-translator.properties`；关闭游戏，用纯文本编辑器设置
`enabled=true` 及其他选项，重新进入游戏或按 `U` 即可载入，`F8` 仍可随时切换总开关。

1. 进入任意世界或服务器，按 `U` 打开设置。
2. 填写目标语言，例如简体中文使用 `zh-CN`、繁體中文使用 `zh-TW`。也可以点击右侧
   快捷按钮，在简体中文、繁體中文和 English 之间切换。
3. 优先选择“离线”；也可以选择内置在线服务、OpenAI 兼容服务或自定义 HTTP JSON API。
4. 选择是否允许发送聊天内容、其他界面文字，以及是否使用本地缓存。
5. “显示”默认选择“仅译文”，直接替换可以防止记分板和箱子界面因双语拼接溢出；需要时仍可切换为“原文+译文”。
6. “混合文本仅译英文”默认开启，已有中文不会再次送去翻译。
7. 选择译文颜色；选择“保留原色”可以关闭颜色区分。
8. 阅读界面中的隐私提示，然后打开“自动翻译”并保存。

“发送翻译”默认关闭。需要把自己发送的消息翻译成服务器使用的语言时，可单独开启，
并在右侧填写发送目标语言（例如 `en`、`ja`）。命令不会翻译；翻译失败或译文超过该
Minecraft 版本的聊天长度限制时会发送原文并在本地提示。

`F8` 是翻译总开关，按一次立即开启或关闭，不需要打开设置页。`U` 和 `F8` 都可以
在“设置 → 控制 → 按键绑定 → MC Auto Translation Tool”中改成其他按键。
每次进入服务器约三秒后，聊天栏也会显示一次按键提示。该提示由客户端直接加入
本地聊天界面，不会作为玩家消息发送到服务器。

## 离线翻译（推荐）

离线模式不需要 API Key，也不需要项目方或 Minecraft 服务器安装任何服务。新安装
默认使用以下配置：

```properties
provider=offline
display-mode=translated-only
translate-english-only=true
translated-text-color=aqua
offline-auto-download=true
offline-model=lite
api-fallback=false
```

首次出现需要翻译的文字时，模组会在后台下载对应平台的 llama.cpp 引擎（约
10–17 MB）和 Lite 模型（491,400,032 字节）。下载期间游戏继续显示英文原文，
不会阻塞渲染；网络中断后会保留 `.part` 文件并在下次请求时续传。完整文件只有在
大小和 SHA-256 都匹配后才会使用。模型默认优先从 ModelScope 国内源下载，失败后
自动回退 Hugging Face 官方源；引擎使用加速源并回退 GitHub 官方发布文件。

默认 `lite` 模型适合先测试。如果电脑至少有约 4 GB 可用内存并希望提高翻译质量，
按 `U` 打开设置，把“离线模型”切换为 `Quality` 后保存即可。设置会立即重新初始化
翻译服务，并在第一次需要翻译时按需下载对应模型。也可以关闭游戏后手动修改：

```properties
offline-model=quality
```

Quality 模型为 1,117,320,736 字节，会自动按需下载。两个模型都是多语言模型，
因此英文之外的常见语言不需要每种语言安装一个单独 JAR。模型和引擎位于：

```text
config/universal-translator-offline/
```

模组会启动只监听 `127.0.0.1` 的本地子进程，退出游戏或重新应用配置时将其关闭。
运行日志位于该目录的 `llama-server.log`。

设置页中的“翻译诊断”会显示当前服务、目标语言、离线模型、模型文件完整性、
自动下载、磁盘缓存和最后运行状态。诊断页不会显示 API 端点、密钥或服务器文字，
并会在打开期间实时更新下载与启动状态。

若希望离线安装或启动失败后尝试现有 LibreTranslate API，可开启“API 回退”。此时
文字可能会发送到 API；默认保持关闭。回退服务可通过配置修改：

```properties
api-fallback=true
api-fallback-provider=libretranslate
```

### 使用腾讯混元翻译（旧兼容接口）

1. 在腾讯云完成实名认证并开通“腾讯混元大模型”。
2. 创建仅允许调用混元翻译的子账号 API 密钥，不要使用主账号长期密钥。
3. 先保持游戏关闭，用纯文本编辑器打开游戏实例中的
   `config/universal-translator.properties`。
4. 修改以下三行；等号后填写你自己的值，不要把配置文件或密钥发给别人：

```properties
provider=tencent-hunyuan
tencent-secret-id=你的SecretId
tencent-secret-key=你的SecretKey
```

默认模型是 `hunyuan-translation-lite`。如果需要完整模型，可另外修改：

```properties
tencent-model=hunyuan-translation
```

保存文件后启动游戏，按 `U`，确认“翻译服务”为“腾讯混元”，再开启自动翻译。
请在腾讯云控制台自行确认当前额度、计费状态与消费上限。

此选项仅为兼容 0.1.x 配置而保留。旧混元平台已公告将在 2026-09-30 停止服务，
不建议为新安装创建长期密钥；优先使用离线或 LibreTranslate 模式。

### 使用 LibreTranslate

默认地址 `http://127.0.0.1:5000/translate` 只代表用户电脑上的本地服务；项目
并没有在这个端口启动服务。没有可用翻译服务时，游戏会继续显示原文，不会卡住。

远程服务必须使用 `https://`。如服务需要密钥，请关闭游戏后，在游戏实例的
`config/universal-translator.properties` 中本地填写 `api-key=`；不要把这个文件
发给别人，也不要在聊天、Issue 或截图中暴露密钥。

### 使用本地或在线 LLM API

控制面板把服务切换到“LLM API”，再点击“LLM API 设置…”。此模式兼容 OpenAI
`/v1/chat/completions` 格式，可以连接在线服务，也可以连接用户自行运行的
llama.cpp、Ollama 等本地兼容服务。默认地址是：

```text
http://127.0.0.1:8080/v1/chat/completions
```

本地服务可不填密钥；在线服务必须使用 `https://`。填写密钥时，设置页不会回显
已经保存的密钥：留空表示保留，输入单个 `-` 表示清除。地址、模型名和密钥只保存在
当前游戏实例的 `config/universal-translator.properties`，不要上传或截图公开。
模组不会负责安装或启动第三方 LLM 服务；有足够显存或内存的用户可以自行选择更大、
质量更高的模型。

### 其他在线服务和自定义 API

1.3.3 内置百度、腾讯云 TMT、阿里云机器翻译、有道、火山引擎机器翻译、讯飞、
华为云，以及 DeepSeek、通义千问、火山方舟和智谱。也可自定义 HTTPS／本机回环
HTTP JSON 请求模板、请求头和响应 JSON 路径。完整的 `provider` 名称、配置字段、
示例和安全限制见 [在线翻译 API 配置](ONLINE_APIS.md)。

## 能翻译什么

模组在最终文字渲染层工作，因此即使尚未进入世界，也能覆盖使用 Minecraft 原版字体
渲染器的模组设置页、任务书、配方/物品界面和整合包自定义标题屏；进入世界后还会
覆盖聊天、记分板、Tab、Action Bar、标题、Boss Bar、菜单/容器标题、物品名与
Lore、工具提示、书、告示牌、全息文字和实体名称。玩家名、当前服务器 IP/域名、
端口地址、网址、数字、百分比、时间数值
和 Minecraft `§` 格式代码会在本机分离。玩家名默认原样保护；开启“玩家名称翻译”后，
玩家名会参与翻译，其他地址、数字与格式字段仍不会发送给翻译模型或 API。

设置中的“翻译屏蔽关键词”接受逗号、分号或换行分隔的内容，不区分大小写。原文只要
包含任一关键词，整段文字就会保持原样且不会进入翻译服务。例如填写 `hello,广告` 后，
包含 `hello` 或“广告”的聊天、界面文字与发送翻译都会跳过。

对于“Welcome 欢迎”之类的混合文本，默认只把 `Welcome` 交给翻译服务，已有的
“欢迎”会在本机原样拼回。此行为可在设置中关闭。译文默认显示为青色，
也可以选择绿色、金色、浅紫、黄色、白色或保留原色。

服务器或整合包若把文字做成图片，或第三方模组完全绕过原版字体渲染器，则无法自动捕获。
复杂的多色 Text 组件在译文中目前可能只保留第一段样式，但原始点击/悬停数据
不会被写回或发送给服务器。

## 缓存与隐私

- 原文不会以明文形式写入缓存文件；缓存键是 SHA-256 哈希。
- 玩家名默认不会进入模型请求；只有主动开启“玩家名称翻译”后才会参与翻译。
- 命中屏蔽关键词的整段原文不会进入模型请求。
- 服务器地址、数字和已有中文不会进入模型请求，只在本机重组显示文本。
- 译文会保存在本机，以减少重复请求和记分板刷新延迟。
- 可在设置中关闭磁盘缓存；重启后仍会有仅限当前运行期间的内存缓存。
- 关闭“聊天内容”可阻止聊天 HUD 文本送往服务；关闭“其他界面”可阻止服务器界面、
  模组菜单和整合包内容送往服务。
- “发送翻译”独立控制玩家主动发送的普通聊天；默认关闭，命令始终不翻译。
- 总开关关闭后，不会产生新的翻译请求。

## 常见问题

**文字一直没有翻译**

确认总开关已开启。离线模式首次使用需要下载约 502 MB，可重新按 `U` 查看状态，
并检查 `config/universal-translator-offline/llama-server.log`。如果存在 `.part` 文件，
表示下载尚未完成，保持联网后再次进入服务器即可续传。API 模式还需确认端点确实
可访问、远程地址使用 HTTPS。第一次看到新句子时都会先显示原文，后台处理完成后
才在后续帧显示译文。

**服务器很卡，需要把服务器交给项目测试吗**

不需要。模组纯客户端运行，开发与绝大多数测试不依赖服务器。最终兼容性测试可
使用普通测试服务器；卡顿服务器只适合以后专门验证高延迟场景。

**发送翻译会影响聊天签名或要求服务器安装模组吗**

服务器不需要安装模组。关闭“发送翻译”时，模组不修改出站消息；开启后，原消息会在
本地翻译完成，再通过 Minecraft 自带的正常发送入口作为一条新消息发送。现代版本仍由
客户端按原版流程签名，但签名对应的是最终译文，不是输入框中的原文。

## 当前版本说明

这是 `1.3.3` 正式版。27 个精确构建目标会整理为 13 个可安装 JAR；所有目标均需完成
干净构建、共享核心自测和发行结构校验，Fabric 整合包还会执行真实 Loader 自动选版测试。
仍建议在更新前备份配置。
发现某个界面漏译时，请记录 Minecraft 版本、加载器版本、界面
位置和 `latest.log`，不要附带 API 密钥或私人聊天内容。
