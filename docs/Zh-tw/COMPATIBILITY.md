## 「支援所有版本」的原則

Minecraft 各時代的載入器、Java 版本、彩現 API 及文字元件結構不同，無法以單一
JAR 安全涵蓋所有 Java 版。專案會依具代表性且長期使用的版本逐一轉接，並為每條發佈線
保留獨立 JAR。只有完成建置、啟動及伺服器內介面迴歸後，才會進入「已驗證」表。

後續候選順序：

1. 1.12.2 Cleanroom；
2. 1.7.10 Forge；
3. 1.16.5 Forge；
4. 1.18.2 Forge/Fabric；
5. 1.21.1 Fabric/NeoForge；
6. 後續仍有較多玩家使用的新版本。

「鄰近版本」不會靠放寬 `fabric.mod.json` 或 `mods.toml` 的版本範圍來猜測支援。
例如 1.20.1 JAR 會明確拒絕 1.20.2，Fabric 與 Forge 也絕不混用。細微的方法描述符
或事件 ABI 變更可能在啟動時造成 Mixin 失敗。鄰近版本可以共用核心，但必須新增
平台轉接並通過同一套建置、映射、啟動及伺服器內迴歸後才會正式列出。

## 伺服器內迴歸清單

- 聊天、計分板、Tab 清單、Action Bar、標題及 Boss Bar；
- 箱子／選單標題、物品名稱與 Lore、告示牌、書、實體名稱及全息文字；
- 尚未進入世界時的模組設定頁、任務書、配方介面及整合包自訂標題畫面；
- 使用 Minecraft 原版字型的模組／整合包文字可擷取，圖片文字及自訂彩現器則為明確限制；
- 玩家自行輸入及傳送的聊天維持原文；
- 線上玩家名稱、本機名稱、伺服器 IP／網域名稱／連接埠維持原樣；
- 既有中文不重複翻譯，英文片段可以翻譯；
- 僅譯文模式不會產生雙語溢出，顏色選項有效；
- `U` 控制面板及 `F8` 總開關可在不同視窗尺寸下使用；
- 模型下載中、下載失敗或離線引擎失敗時，遊戲不會凍結並會繼續顯示原文。
