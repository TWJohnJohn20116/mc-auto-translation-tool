# MC 自動翻譯工具安裝及使用指南

[简体中文](../Zh-cn/USER_GUIDE.md) · [繁體中文](USER_GUIDE.md) · [English](../en/USER_GUIDE.md) · [返回繁中 README](README.md)

## 選擇正確的檔案

每個 Minecraft 版本必須使用對應的 JAR，不可混用：

| Minecraft | 模組載入器 | Java | 另需安裝 |
| --- | --- | --- | --- |
| 26.1、26.1.1、26.1.2、26.2（單一 JAR） | Fabric | 25 | 對應版本的 Fabric API |
| 1.21–1.21.11（單一 JAR） | Fabric | 21 | 對應版本的 Fabric API |
| 1.21.11 | Forge 61.2.0+ | 21 | 無額外模組 |
| 1.21.11 | Fabric | 21 | Fabric API |
| 1.20.1 | Forge 47.4.10+ | 17 | 無額外模組 |
| 1.20.1 | Fabric | 17 | Fabric API |
| 1.19.2（尚未發佈 JAR） | Fabric | 17 | Fabric API |
| 1.16.5（尚未發佈 JAR） | Fabric | 8 | Fabric API |
| 1.12.2 | Forge 14.23.5.x | 8 | 無額外模組 |
| 1.8.9 | Forge 11.15.1.x | 8 | 無額外模組 |

將正確的 JAR 放入該遊戲執行個體的 `mods` 資料夾。伺服器不需要安裝本模組。
1.20.1 與 1.21.11 JAR 只接受表中的精確遊戲版本，不可用於鄰近版本，也不可在
Fabric 與 Forge 之間混用。

## 首次設定

以下圖形設定步驟適用於 Fabric 與舊版 Forge。Forge 1.20.1／1.21.11 首次啟動後會
產生 `config/universal-translator.properties`；關閉遊戲，以純文字編輯器設定
`enabled=true` 及其他選項，重新進入或按下 `U` 即可載入，`F8` 仍可隨時切換總開關。

1. 進入任意世界或伺服器，按 `U` 開啟設定。
2. 填寫目標語言，例如簡體中文使用 `zh-CN`、繁體中文使用 `zh-TW`。也可按右側
   快速按鈕，在簡體中文、繁體中文及 English 之間切換。
3. 優先選擇「離線」；也可以選擇內建線上服務、OpenAI 相容服務或自訂 HTTP JSON API。
4. 選擇是否允許傳送聊天內容、其他介面文字，以及是否使用本機快取。
5. 「顯示」預設選擇「僅譯文」，直接取代可防止計分板及箱子介面因雙語串接而溢出；需要時仍可切換為「原文＋譯文」。
6. 「混合文字僅翻譯英文」預設開啟，既有中文不會再次送去翻譯。
7. 選擇譯文顏色；選擇「保留原色」可以關閉顏色區分。
8. 閱讀介面中的隱私權提示，接著開啟「自動翻譯」並儲存。

「傳送翻譯」預設關閉。若要把自己送出的訊息翻譯成伺服器使用的語言，可另行開啟，
並在右側填寫傳送目標語言（例如 `en`、`ja`）。命令不會翻譯；翻譯失敗或譯文超過
該 Minecraft 版本的聊天長度限制時，會傳送原文並在本機提示。

`F8` 是翻譯總開關，按一次即可立即開啟或關閉，無須開啟設定頁面。`U` 及 `F8` 都可
在「設定 → 控制 → 按鍵綁定 → MC Auto Translation Tool」中變更為其他按鍵。
每次進入伺服器約三秒後，聊天欄也會顯示一次按鍵提示。該提示由用戶端直接加入
本機聊天介面，不會作為玩家訊息傳送至伺服器。

## 離線翻譯（建議）

離線模式不需要 API Key，也不需要專案方或 Minecraft 伺服器安裝任何服務。新安裝
預設使用以下設定：

```properties
provider=offline
display-mode=translated-only
translate-english-only=true
translated-text-color=aqua
offline-auto-download=true
offline-model=lite
api-fallback=false
```

首次出現需要翻譯的文字時，模組會在背景下載對應平台的 llama.cpp 引擎（約
10–17 MB）及 Lite 模型（491,400,032 位元組）。下載期間遊戲會繼續顯示英文原文，
不會阻塞彩現；網路中斷後會保留 `.part` 檔案，並於下次請求時續傳。完整檔案只有在
大小及 SHA-256 都相符後才會使用。模型預設優先從 ModelScope 中國大陸來源下載，失敗後
自動回退至 Hugging Face 官方來源；引擎使用加速來源，並回退至 GitHub 官方發行檔案。

預設 `lite` 模型適合先行測試。若電腦至少有約 4 GB 可用記憶體並希望提升翻譯品質，
按 `U` 開啟設定，將「離線模型」切換為 `Quality` 後儲存即可。設定會立即重新初始化
翻譯服務，並於第一次需要翻譯時按需下載對應模型。也可以關閉遊戲後手動修改：

```properties
offline-model=quality
```

Quality 模型大小為 1,117,320,736 位元組，會自動按需下載。兩個模型都是多語言模型，
因此英文以外的常見語言不需要為每種語言安裝獨立 JAR。模型及引擎位於：

```text
config/universal-translator-offline/
```

模組會啟動只監聽 `127.0.0.1` 的本機子行程，離開遊戲或重新套用設定時會將其關閉。
執行日誌位於該目錄中的 `llama-server.log`。

設定頁面的「翻譯診斷」會顯示目前服務、目標語言、離線模型、模型檔案完整性、
自動下載、磁碟快取及最後執行狀態。診斷頁不會顯示 API 端點、金鑰或伺服器文字，
並會在開啟期間即時更新下載及啟動狀態。

若希望離線安裝或啟動失敗後嘗試現有 LibreTranslate API，可開啟「API 回退」。此時
文字可能會傳送至 API；預設保持關閉。回退服務可透過設定修改：

```properties
api-fallback=true
api-fallback-provider=libretranslate
```

### 使用騰訊混元翻譯（舊版相容介面）

1. 在騰訊雲完成實名認證並啟用「騰訊混元大模型」。
2. 建立只允許呼叫混元翻譯的子帳號 API 金鑰，請勿長期使用主帳號金鑰。
3. 先關閉遊戲，再使用純文字編輯器開啟遊戲執行個體中的 `config/universal-translator.properties`。
4. 修改以下三行；在等號後填入自己的值，請勿將設定檔或金鑰傳給他人：

```properties
provider=tencent-hunyuan
tencent-secret-id=你的SecretId
tencent-secret-key=你的SecretKey
```

預設模型為 `hunyuan-translation-lite`。如需完整模型，可另外修改：

```properties
tencent-model=hunyuan-translation
```

儲存檔案後啟動遊戲，按 `U`，確認「翻譯服務」為「騰訊混元」，再開啟自動翻譯。
請自行於騰訊雲控制台確認目前額度、計費狀態及消費上限。

此選項只為相容 0.1.x 設定而保留。舊混元平台已公告將於 2026-09-30 停止服務，
不建議為新安裝建立長期金鑰；請優先使用離線或 LibreTranslate 模式。

### 使用 LibreTranslate

預設位址 `http://127.0.0.1:5000/translate` 只代表使用者電腦上的本機服務；專案
並未在此連接埠啟動服務。沒有可用翻譯服務時，遊戲會繼續顯示原文，不會卡住。

遠端服務必須使用 `https://`。如服務需要金鑰，請關閉遊戲後，在遊戲執行個體的
`config/universal-translator.properties` 中於本機填寫 `api-key=`；請勿將此檔案
傳給他人，也不要在聊天、Issue 或螢幕擷取畫面中洩漏金鑰。

### 使用本機或線上 LLM API

在控制面板將服務切換為「LLM API」，再按「LLM API 設定…」。此模式相容 OpenAI
`/v1/chat/completions` 格式，可連線至線上服務或使用者自行執行的 llama.cpp、Ollama
等本機相容服務。預設位址為：

```text
http://127.0.0.1:8080/v1/chat/completions
```

本機服務可以不填金鑰；線上服務必須使用 `https://`。設定頁不會回顯已儲存的金鑰：
留空代表保留，輸入單一 `-` 代表清除。位址、模型名稱及金鑰只儲存在目前遊戲執行個體
的 `config/universal-translator.properties`。模組不會安裝或啟動第三方 LLM 服務。

### 其他線上服務及自訂 API

1.3.3 內建百度、騰訊雲 TMT、阿里雲機器翻譯、有道、火山引擎、訊飛、華為雲、
DeepSeek、通義千問、火山方舟及智譜。也可自訂 HTTPS／本機回環 HTTP JSON 請求範本、
請求頭及回應路徑。詳情請參閱 [線上翻譯 API 設定](ONLINE_APIS.md)。

## 可以翻譯哪些內容

模組在最終文字彩現層運作，因此尚未進入世界時也能涵蓋使用 Minecraft 原版字型的
模組設定頁、任務書、配方／物品介面及整合包自訂標題畫面；進入世界後還可涵蓋聊天、
計分板、Tab、Action Bar、標題、Boss Bar、選單／容器標題、物品名稱與 Lore、
工具提示、書、告示牌、全息文字及實體名稱。玩家名稱、目前伺服器 IP／網域名稱、連接埠位址、網址、數字、百分比、
時間數值及 Minecraft `§` 格式代碼都會在本機分離。玩家名稱預設原樣保護；開啟
「玩家名稱翻譯」後，玩家名稱會參與翻譯，其他位址、數字及格式欄位仍不會傳送至翻譯模型或 API。

設定中的「翻譯屏蔽關鍵詞」接受逗號、分號或換行分隔的內容，且不區分大小寫。原文只要
包含任一關鍵詞，整段文字便會保持原樣且不會進入翻譯服務。例如填入 `hello,廣告` 後，
包含 `hello` 或「廣告」的聊天、介面文字及傳送翻譯都會略過。

對於「Welcome 歡迎」之類的混合文字，預設只會將 `Welcome` 交給翻譯服務，既有的
「歡迎」會在本機原樣重新組合。此行為可在設定中關閉。譯文預設顯示為青色，
也可選擇綠色、金色、淺紫色、黃色、白色或保留原色。

若伺服器或整合包將文字製成圖片，或第三方模組繞過原版字型彩現器，便不會自動擷取。
複雜的多色 Text 元件目前可能只在譯文中保留第一段樣式，但原始點擊／懸停資料
不會寫回或傳送至伺服器。

## 快取與隱私權

- 原文不會以明文形式寫入快取檔案；快取鍵為 SHA-256 雜湊。
- 玩家名稱預設不會進入模型請求；只有主動開啟「玩家名稱翻譯」後才會參與翻譯。
- 命中屏蔽關鍵詞的整段原文不會進入模型請求。
- 伺服器位址、數字及既有中文不會進入模型請求，只會在本機重新組合顯示文字。
- 譯文會儲存於本機，以減少重複請求及計分板重新整理延遲。
- 可在設定中關閉磁碟快取；重新啟動後仍會有僅限當次執行期間的記憶體快取。
- 關閉「聊天內容」可阻止聊天 HUD 文字傳送至服務；關閉「其他介面」可阻止伺服器介面、
  模組選單及整合包內容傳送至服務。
- 「傳送翻譯」獨立控制玩家主動傳送的一般聊天；預設關閉，命令永遠不翻譯。
- 關閉總開關後，不會產生新的翻譯請求。

## 常見問題

**文字一直沒有翻譯**

確認總開關已開啟。離線模式首次使用需要下載約 502 MB，可再次按 `U` 查看狀態，
並檢查 `config/universal-translator-offline/llama-server.log`。若存在 `.part` 檔案，
表示下載尚未完成，保持連線後再次進入伺服器即可續傳。API 模式還需確認端點確實
可以存取，且遠端位址使用 HTTPS。第一次看到新句子時會先顯示原文，背景處理完成後
才會在後續影格顯示譯文。

**伺服器很卡，需要將伺服器交給專案測試嗎？**

不需要。模組完全在用戶端執行，開發及大部分測試不依賴伺服器。最終相容性測試可
使用一般測試伺服器；卡頓伺服器只適合日後專門驗證高延遲情境。

**傳送翻譯會影響聊天簽章，或要求伺服器安裝模組嗎？**

伺服器不需要安裝模組。關閉「傳送翻譯」時，模組不會修改外送訊息；開啟後，原訊息
會在本機背景翻譯，再透過原版聊天入口傳送並由遊戲正常簽章。命令維持原樣。部分採用
額外聊天驗證的伺服器可能有自己的限制，因此此功能預設關閉。

## 目前版本說明

這是 `1.3.3` 正式版。27 個精確建置目標會整理為 13 個可安裝 JAR；所有目標均需通過
乾淨建置、共用核心測試及發行結構驗證，Fabric 整合包亦會執行真實 Loader 自動選版測試。
更新前仍建議備份設定。
發現某個介面漏譯時，請記錄 Minecraft 版本、載入器版本、介面位置及 `latest.log`，
且不要附上 API 金鑰或私人聊天內容。
